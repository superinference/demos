# SuperInference — Demos

Auto-published recordings of the interactive **ami** TUI, consumed by
[www.superinference.org/demos](https://www.superinference.org/demos).

Bundled at the repo root as:

```
<scene-id>/
  <scene-id>.cast   # asciinema recording
  <scene-id>.gif    # rendered animation
  <scene-id>.png    # poster thumbnail
  <scene-id>.yml    # metadata (title, description, model, categories, duration)
index.json          # aggregated manifest the site fetches
```

Note: Do not hand-edit,  this repo is overwritten each publish.
